Features

Every animation primitive, one platform.

01
Visual Timeline

Drag-and-drop animation timeline with keyframe editing, curve editor, and live preview. No code required for the first pass.

02
Scroll-Triggered

Pin sections, scrub animations to scroll position, and reveal elements as they enter the viewport. Built on the Intersection Observer API — no dependencies.

03
Physics Engine

Spring, gravity, and momentum simulations with configurable stiffness and damping. Animations that feel physically real, not mathematically precise.

04
Micro-interactions

Pre-built hover states, click feedback, focus animations, and loading indicators. Import with one line, customise with CSS variables.

05
Text Animation

Character-by-character, word-by-word, and line-by-line reveals. Kinetic typography with full control over stagger timing and easing curves.

06
Export to Code

Export any animation as GSAP, Framer Motion, or vanilla CSS. Every visual edit generates clean, production-ready code.

Code that moves
like you mean it.

KINETIC's API is designed for developers who care about the craft. Declarative syntax, tree-shakeable, and less than 14kb gzipped.

import { animate, scroll, spring } from 'kinetic'

// Scroll-triggered counter with spring easing
scroll('#stats-section', {
  onEnter: () => {
    animate('[data-counter]', {
      from: 0,
      to: attr('data-value'),
      duration: 1400,
      easing: spring({ stiffness: 80, damping: 14 }),
      stagger: 120
    })
  }
})
