Most AI-generated pages look the same. These shouldn't.

The default Claude artifact is a purple gradient on a white page with Inter font and evenly-rounded corners. That's fine for prototyping. It's not design.

This skill is a design system compiler. Each of the 17 trend files encodes a complete aesthetic philosophy — not just colours, but spatial composition, motion curves, typography hierarchy, and explicit anti-patterns. When Claude reads a trend file, it doesn't apply a skin. It thinks in that design language.

The result: artifacts that feel authored, not generated. Every page linked from this showcase was produced by Claude, guided by these skill files, in a single prompt.

The Design Thinking Behind This

Why skills, not prompts

01

Prompts are ephemeral

A good prompt gets a good result once. A skill file encodes the knowledge so that every future prompt benefits. It's the difference between catching a fish and building a fishery.

02

Design systems, not themes

Each trend file doesn't just set colours — it defines layout philosophy, motion principles, typography rules, anti-patterns, and explicit do/don't guidance. Claude thinks differently after reading each one.

03

Composable by design

Trends layer naturally. Dark Mode + Neumorphism. Retrofuturism + Bold Typography. The skill file documents which combinations work and which conflict — Claude inherits that judgement.

04

Anti-slop engineering

Every trend file includes explicit anti-patterns: no centred everything, no purple gradients, no uniform border-radius, no Inter. The skill actively prevents the generic AI aesthetic.
